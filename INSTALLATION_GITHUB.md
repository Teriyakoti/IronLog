# Installation GitHub

1. Importer tous les fichiers, y compris `.github`.
2. Dans **Settings → Pages**, choisir **GitHub Actions** comme source.
3. Vérifier le workflow dans l’onglet **Actions**.
4. Ouvrir l’URL GitHub Pages dans Safari.
5. Utiliser **Partager → Sur l’écran d’accueil → Ouvrir comme app web**.

## Nouvelle fonctionnalité

1. créer une issue ;
2. créer une branche ;
3. faire les commits ;
4. ouvrir une pull request ;
5. fusionner dans `main` ;
6. créer une release pour une version importante.
